01

what it is

rm_01
two effects
a 16-tap stereo rhythm delay + a 64-tap comb resonator, 0.1 ms to 20 s
every tap
its own level, pan, filter (lp · bp · hp) and pitch shift
the comb
long = echoes · short + high feedback = karplus-strong plucks and pitched ringing
inside
96 kHz / 32-bit fpga · 128 preset slots

›tap#

the taps

rm_03 · tap edit buttons
[ mute ]
in this view the 16 buttons toggle each tap
[ level ]
0 – 15, exponential · 0 = off
[ pan ]
7L … 0 … 7R (balance in stereo)
[ cut ] [ q ] [ type ]
filter per tap: cutoff ~Hz, q 0 – 15, none · lp · bp · hp
[ pitch ] twice
−16 … +15 semitones · press again for detune
all at once
in edit mode: push the encoder, turn = every tap · push twice = 8 ramp shapes

04

rhythm · time

rm_04 · fig.01
[ grid ]
taps per beat: 1 2 3 4 6 8 12 16 · tap n lands at n ÷ grid beats
[ piles ]
the tap stack · taps share the time of the last tap in the pile
[ tempo ]
tap 3 times · a clk input overrides it · clock div /1 – /256
[ type ] [ amt ]
groove: 16 types (swing, accelerando, waltz, random, reflections …) · amount 0 – 100
[ tap# ] (feedback)
which tap repeats: 1 – 16, all, or the comb size · push = ping-pong

06

routing · trigger · mod

rm_06 · fig.02
[ routing+config ]
press to cycle: routing · input mode · trigger mode
routing
dly › cmb · cmb › dly · both in parallel · L = dly, R = cmb
trigger
big red button + trig jack: ping, freeze, reverse, randomize, clear, next preset, mutes …
mod a mod b
press [ mod a ] or [ mod b ], turn to a destination, push to lock it
note
mod A is normalled to mod B · only mod B can set delay time
07

quiet? distorted?

rm_07 · levels
[ meters+gain ]
shows in · out · delay and comb feedback · sets their output gain
delay gain
about 8 – 10 for 1 – 2 taps · lower it as taps pile up
inputs
attenuators near noon suit normal eurorack levels · keep IN off the top
high q
tap filters at high q can distort · turn the input down
two mixes
mix pot = analog dry/wet · the wet/dry page = inside the delay
