# rainmaker-navigator

travelers guide for seeding the storm clouds: a one-page reference for the **intellijel rainmaker**, the 16-tap stereo rhythm delay and 64-tap comb resonator. the two edit modes, the taps, rhythm and groove, the comb, routing, triggers and mod, levels, presets and specs.

sources: the intellijel rainmaker manual (panel photo from its front-panel figure).

not affiliated with intellijel or cylonix.
